# Security policy

## Supported versions

Security fixes target the latest published release. Check [Releases](https://github.com/JesusCenMon/ETS2-Discord-Presence/releases/latest) before reporting.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/JesusCenMon/ETS2-Discord-Presence/security/advisories/new). Include the affected version, steps to reproduce, expected impact and a minimal example.

Keep credentials, personal recordings and private paths out of public issues. A normal UI bug or a telemetry compatibility problem belongs in the [bug report form](https://github.com/JesusCenMon/ETS2-Discord-Presence/issues/new/choose).

Reports are reviewed by the maintainer. A response time is not guaranteed.

## En español

Informa vulnerabilidades mediante el enlace privado de arriba. Incluye la versión afectada, los pasos para repetir el problema y su impacto. Para fallos de interfaz o compatibilidad del juego, usa el formulario público de errores.
