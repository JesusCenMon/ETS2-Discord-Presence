# Community Code of Conduct

We welcome players and contributors in English and Spanish, regardless of experience, background or identity.

## Expected behavior

- Be respectful, patient and specific.
- Critique ideas and code constructively.
- Respect privacy and ask before sharing someone else's personal information.
- Keep issues and discussions relevant to the project.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing and spam are unacceptable.

## Reporting and moderation

Report problematic public content using GitHub's **Report content** action. For a private concern, use the contact options on the [maintainer's GitHub profile](https://github.com/JesusCenMon). Avoid repeating private or harmful material in a public issue.

The maintainer may edit or remove content, lock conversations or restrict participation to protect the community. Decisions should be proportionate to the behavior and its impact.

## En español

Esta comunidad recibe jugadores y colaboradores en español e inglés. Trata a los demás con respeto, acepta las críticas constructivas y protege la información personal. El acoso, las amenazas, la discriminación y el spam no se permiten.

Usa **Report content** de GitHub para informar contenido problemático, o las opciones de contacto del perfil del mantenedor para una situación privada.
